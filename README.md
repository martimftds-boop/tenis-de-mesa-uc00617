# Ténis de Mesa

Projeto individual para a UC00617, com uma página de apresentação sobre o ténis de mesa.

## Descrição
Este repositório contém uma página estática em HTML que apresenta os conceitos básicos do desporto, incluindo o que é, o material necessário e as regras mais importantes.

## Como usar
1. Clona o repositório.
2. Abre o ficheiro `index.html` diretamente no navegador, ou serve a pasta com um pequeno servidor local.

## Estrutura do projeto
- `index.html` — página principal com a apresentação do tema.
- `README.md` — descrição do projeto e instruções de utilização.
- `.gitignore` — ficheiros que não devem ser versionados.
- `LICENSE` — licença do projeto.
